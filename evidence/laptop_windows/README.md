# Evidencias de la laptop Windows

**Estado: pendiente.** Esta carpeta está vacía hasta que un integrante ejecute el proyecto en su laptop.

Qué debe quedar aquí (ver `README.md` principal, sección «Reproducir desde cero en Windows»):

- `entorno_windows_<fecha>.txt`, generado por `scripts\windows\verificar_entorno.ps1`.
- Los archivos que guarda `python -m aerolinea --evidencia evidence\laptop_windows reproducir --confirmar-destruccion` (conexión, carga, pruebas).
- La comparación de los CSV generados con `data/sintetico/manifiesto.json` (SHA-256).

No guardar aquí archivos `.env`, contraseñas ni capturas que muestren datos personales.
